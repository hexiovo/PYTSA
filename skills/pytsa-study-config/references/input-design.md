# 输入采集与决策台账

以下专业条目是AI内部检查清单，不直接逐条问主试。统计估计量、编码、效应量、校正及处理参数由AI据设计提出建议；只向主试核实研究事实、目标与已有约束，并把必要问题改写成普通话。

## 一次集中询问

先说明：“我会把实验设计转成 PYTSA 可执行设置及单独的统计材料；下面只问会改变处理路线或结论的问题。”将未知项合并成一轮普通话问题，标为“已知 / 建议 / 缺失”。先读取用户提供的文件和设备资料，不让主试重复回答可查到的事实。不能从数值推断研究意图。

### 研究设计
- 研究问题、主要/次要结局、主要比较、方向假设和主要分析家族是什么？
- 独立抽样/实验单位是什么（人、动物、样本、场次、批次）？同一单位是否有多条件、多时点、试次或会话？
- 分配、随机化、平衡、交叉、顺序和洗脱如何定义？有组间、组内或嵌套/交叉刺激因素吗？
- 纳入/排除和停止规则、预注册、多重比较家族是什么？
- 目标是描述、预测、组间推断、重复测量推断，还是多种？如何区分探索与确认分析？

### 文件与信号
- 原始文件、字段说明、工作簿和 sheet 名是什么？文本编码、分隔符、小数点、日期格式及缺失码是什么？
- 每行代表采样点、事件、被试、条件还是汇总值？文件是 long 还是 wide？ID、会话、条件、时间、信号列分别是哪列？
- ID 是否带前导零？能否一直按字符串读取？多表合并预期是 1:1、1:many、many:1 还是 many:many？主键是什么？
- 设备、硬件采样率、信号单位、量程、校准、饱和值和有效信号范围是什么？
- 时间戳来自设备还是软件？单位是秒、毫秒、采样点还是日期时间？时区、丢包、抖动、重启如何记录？
- 事件表示瞬时点、刺激起止、持续状态还是只在起始采样点留下标签？事件时间是绝对还是相对记录起点？
- 多设备同步使用何种脉冲/锚点？已知时钟偏移、漂移和同步误差是多少？

### 预处理、转换与统计
- 用哪些通道和记录区间？伪迹/质量规则、缺失段上限、无效事件和排除规则是什么？
- 要不要重采样？目标 fs 和理由是什么？抗混叠滤波、边界与事件时间映射怎么处理？
- 需要何种设备单位换算、滤波、去趋势、尖峰处理、平滑、变换、基线或特征聚合？哪些必须禁用？
- 是否预测？目标时点、部署时可见历史、horizon、验证切分和部署单位是什么？
- 要报告何种效应量/区间/对比编码/校正？是否存在聚类、随机效应、时间自相关或重复测量？

问题必须让不懂术语的主试能回答，可给简单例子但不暗示答案。关键值未知时，明确哪个阶段因此 pending、需要谁提供哪份资料。不要用推荐默认值掩盖缺失的研究事实。

## 标签与台账

- KNOWN：来自用户、原始文件、设备手册、校准报告、代码或实际运行；附原文、文件路径/页/列/哈希。
- RECOMMENDED：AI建议且尚未由用户或证据确认；附理由、替代方案和对结果的影响。
- MISSING：缺关键输入；用 null 保持缺失，标明阻断的阶段和待询问人。

每个参数记录路径、值、单位、来源、依据、软件版本、适用条件/分支、影响、验证状态/证据和真实备选。研究决定和软件默认分开保存；用户确认建议后记录确认来源和日期，不能静默覆盖旧版。

## 文件结构与主键

1. 以只读方式读原件，记录文件名、大小、SHA-256、来源和日期；所有加工另存派生数据。
2. 指定工作簿/工作表、标题行、隐藏列、合并单元格、编码、分隔符和缺失标记。载入后检查列名、dtype、首尾值、行数、唯一键、缺失、有限性和时间跨度。
3. ID 在解析初期指定为字符串，例如 0012 必须始终保持前导零；不能先变成数值再猜宽度补零。
4. long 表通常每行是单位×条件×时间/事件观测；wide 表常将条件/时间展开为列。reshape 必须声明键、目标单位、转换前后行数和配对保留方式。
5. 合并前输出各表重复键、唯一键数、未匹配行数；按预期 cardinality 强制 merge。many-to-many 仅在研究设计明确允许并能证明键关系时使用，不能让连接扩张生成伪独立观测。
6. 事件表包含被试/会话键、事件ID、标签、开始时间；区间事件另有结束时间。先按被试/记录映射，再检查越界、重复、乱序和重叠。

遇到无法证明的独立单位、单位、采样率、事件零点、时钟同步或表格键时，先完成不依赖部分，再停止会改变结论的分支。
