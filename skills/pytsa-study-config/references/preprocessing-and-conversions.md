# 预处理、转换与分支

## 显式分支

保留 raw 原文件只读；将 physical（已核实单位/时间与设备结构）和 exploratory（探索性填补、滤波或变换）分开；model/feature 分支另存用于建模的输出。特征/变换参数仅在训练资料上拟合，再应用于留出数据。

PYTSA prepare_data 的 data 和 original 不是原始文件与副本：original 已经过入口中的去重和可能的重采样，保留物理值分支；它不等于文件字节级原始数据。探索性缺失填补、预处理、滤波和 transform 只作用于 data。预测使用 prepared["original"]，EDA 也读 original。不能因名字叫 original 就声称未经整理。

## 单位、时间与时钟

- 写清来源单位、目标单位、比例/公式、校准依据、适用设备和有效范围。电阻到电导只有当设备文档证明数值确为电阻时才用 G=1/R；若 R 单位为 Ω，G(µS)=10^6/R(Ω)。零/超量程/桥路、电压、偏置或任意设备输出不能直接套公式，不能只改列名。
- 电压、计数到物理单位需设备增益/零点/校准曲线；无校准就保留原单位并限制跨设备比较。所有换算保留原列与派生列。
- 统一成秒作为内部时间，并记录时间原点和时区。优先取设备采样率；只有时间戳严格递增且稳定等间隔时，可用 fs=1/median(diff(t_seconds)) 估名义值，同时报告间隔、抖动、丢包，不以行数代替 fs。
- 事件标记区分采样点、状态边沿、区间开始/结束。连续标签不能每行重复计作事件；ms→s 换算须固定零点并用已知点做数值断言。
- 多设备按硬件脉冲或共享锚点估计偏移。线性漂移需要多个跨时段锚点；单锚点不能识别漂移。校正后报告剩余同步误差、事件不确定度和使用的模型。
- 时间回拨、设备暂停、重启或采集断点应切成新连续段，不强行用单个 fs 连接。

## 长宽表、重采样与缺失

- 先按设计决定 long/wide 目标结构，保存转换键和行级来源。重塑后核对每被试/条件数量、重复键和不完整配对。
- 降采样必须先抗混叠再抽取，列明原/目标 fs、截止频率、通阻带、滤波器、边缘处理、事件时间映射和相位/延时；可用经验证实现如 scipy.signal.resample_poly。分箱均值不是带完整抗混叠保证的 polyphase 重采样。上采样不会增加信息。
- 插值前列出各通道连续缺口长度和边界，规定最长缺失时长/点数。只考虑短的内部缺口；不跨被试、会话、条件、刺激或不连续段插值。缺口边界不外推，原缺失掩码保留。
- 前向填充仅在因果且物理含义成立时使用；不能从未来回填历史。PYTSA 线性插值只限内部并只影响探索数据；边界空缺仍会失败。
- prepare_data 的 resample 是按秒分箱、选中信号列箱均值，空箱缺失；技能必须显式注明此实现，不把它说成抗混叠重采样。

## 滤波、去趋势、尖峰、小波和平滑

- 对每个滤波记录类型、阶数、cutoff、fs、通带/阻带、Nyquist、相位、初始状态/边缘规则与软件版本；必须满足 0 < cutoff < fs/2。先评估最短连续段。
- 双向零相位滤波使用未来样本，不可因果；短段不满足 pad 长度时需失败/另选有根据的方法，不能静默缩短滤波阶数。保留首尾边缘质量说明。
- PYTSA Butterworth 在探索分支；核对实际 filter_phase 和短段约束。预测/实时任务不能默认应用零相位滤波。
- 去趋势写明模型阶数和范围，按连续段处理。去尖峰先标记并记录幅度阈值、单位和数量；不自动删除。平滑需声明窗长/步长/边界/频域影响。
- 小波需写基函数、分解层、阈值、重构和边界影响，不适用时明确关闭。不要叠加滤波、平滑与去趋势而不检查峰值、峰宽及功率谱。
- 有短段、断点、事件附近或不同条件的选择性伪迹时，单次全局滤波可能不合理；无法证明方法适用则留为建议或 pending。

## 变换、标准化和差分

- log 与 Box-Cox 要求正值。遇到零/负值不擅自加常数；先确认测量尺度/物理偏移。Yeo-Johnson 可处理零负值，但 λ 必须在训练集估计并存档。
- 写明变换目标、拟合数据范围、输出尺度、逆变换方法与回转偏差。跨训练/测试时参数只用训练数据拟合。
- 标准化范围须明确为每人/每段/基线/训练集/全体。跨折预测中均值方差、变换参数、特征选择只能在训练折拟合。
- 一阶差分是 x_t-x_(t-1)；明确标记到前点还是后点。PYTSA 差分标记为后一个采样时刻并移除首行。报告差分后尺度；需要还原时保存训练末值并累加，不把差分均值误作原始水平变化。
- 不同被试或条件的标准化可能抹去水平差异；只有研究问题允许时使用。

## 基线、事件窗与 SCR

声明相对事件起止、单位、半开/闭端点、重叠规则、无效样本比例、响应窗和基线算法。减法是 response-baseline（原单位）；比值为 response/baseline（基线近零时不稳）；百分比为 100*(response-baseline)/baseline（分母需阈值）。不得看到结果后挑窗。

区分每级记录：采样点→连续段→窗口→事件→会话→被试→组。窗口长、步长、重叠与边界都要记录；特征聚合需要函数、单位、分母、有效样本/事件下限和 QC 规则。有效响应窗内无符合阈值的 SCR 才记无响应 0；窗口缺失/越界/被伪迹隔离/分析失败记 NA 或 unavailable，并保留原因。不可把 NA 变零。

PYTSA EDA 的事件时间以记录起点为零的秒；它读取物理 original，要求单位、采样率和连续段。具体约束见 pytsa-contract.md。

## 预测防泄漏

按未来部署场景切分，先按被试/实验单位分组，时间序列保持先后。归一化、滤波拟合参数、插补模型、特征筛选、超参数只在训练折估计。重叠窗或延迟标签时设置合适 purge/embargo。说明目标 horizon、预测时可见变量和基线模型。留后/CV 表现不是外部验证；折数和窗口数都不是 n。
