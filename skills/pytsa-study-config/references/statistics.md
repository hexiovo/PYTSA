# 最终统计计划

## 先确定估计对象和独立单位

统计方法从研究问题和随机化/抽样设计决定。先写明结局、量尺、独立实验单位、观察层级、组内/组间因素、重复结构、目标估计量和总体范围。每一行观测不代表一个独立样本。被试、样品、时间、试次、刺激、会话/地点可能是不同层级。

- 同一独立单位测两次、一个预定比较：配对模型；先按字符串 ID 对齐成每人一个差值。
- 不重叠的独立组、每单位一个值：独立组比较，并证明随机化/抽样独立。
- 多条件/时间点、试次或不平衡观测：按结构考虑重复测量/混合效应；定义被试、刺激等随机截距，是否需要随机斜率及嵌套/交叉关系。
- 含组间与组内的混合设计不可用只适用于平衡纯被试内的 AnovaRM 顶替。模型稀疏/不收敛时按预先定义的失败预案处理，不偷偷换模型挑显著。
- 连续、二元、计数、序数和时间到事件结局需要匹配分布/链接；不能所有结果都用普通正态线性模型。
- 一个被试的窗口、SCR 峰、事件、多个条件行、采样点或 CV 折不能作为新增独立样本；要么汇总到实验单位，要么以模型保留依赖。

## 预先规定的统计输出

统计计划和台账至少含：
- 主要/次要/探索性结局和假设；每个多重比较 family 的成员。
- 主要估计量、对比矩阵、组顺序、类别编码（reference/treatment/sum/effect）和方向。
- 缺失、伪迹、无效事件、无反应 0 和 unavailable NA 的区别；纳入/排除规则和每阶段的实际 n。
- 模型形式、误差分布/连接函数、相关/随机效应结构、假设诊断与失败/敏感性预案。
- 估计值、标准误、置信区间、精确 p 值、效应量及解释尺度。配对均值差可报告 Cohen dz；独立组可报告设计匹配的 Hedges g；二元结局选择 OR/RR/风险差及区间。
- 双侧/单侧选择、alpha 和理论依据。不可把单侧改向或检验筛选当提高显著性的工具。
- 按完整预声明 family 使用 Holm、BH/FDR 或研究指定方法；记录 family 数量、原始和调整后结果。不能事后删掉不显著项再校正。
- 不用“先做正态性检验，p 大于 .05 就参数法，否则非参数”当开关；诊断残差图、异方差/离群、时间自相关、随机结构、收敛和可识别性。按模型假设决定稳健性/敏感性分析，而非追逐显著性。

## 缺失、诊断和稳健性

描述缺失发生层级和机制假设。区分失访、缺单次记录、伪迹、事件时间窗无效、有效响应窗内确无 SCR。仅最后一种才可能是 count=0；不可判定时为 NA。报告每个模型实际包含的单位/配对/聚类数和排除原因。

按适用模型检查残差 vs 拟合、残差分布、方差结构、时间自相关、随机效应/收敛、过度离散/零膨胀、影响点与可识别性。诊断用于理解模型偏差，不作事后选择最显著路线的循环。

敏感性分析预先限量并写原因，例如有理论依据的阈值、窗口、伪迹处理或协方差结构。各路线都报告，不能择显著一条作为主结果。缺失处理方法要基于设计及其假设；简单删失/插补不是默认真理。

## 数据聚合和防伪重复

- ID 始终保留字符串；配对前断言每个 ID-condition 唯一、条件齐全、合并键 cardinality 正确。
- 输出被试/实验单位级表，与采样点、窗口、事件特征表分开。记录从底层到上层的聚合函数、单位、有效分母和 QC。
- 同一个被试多行不能交给独立样本 t 检验。重复数据有意义时用与实验结构匹配的模型/聚类稳健方法。
- 预测验证按未来部署场景分组切分；变换、筛选、标准化、缺失模型和调参只在训练折拟合。折数不是样本数。

## 外接脚本契约

如果 PYTSA 无所需推断入口，未来 AI 生成 statistics/analysis-plan.json 和必要的 statistics/run_statistics.py。声明 Python/依赖版本、命令、输入字段、排序和 ID 类型、筛选规则、输出目录/覆盖策略、随机种子。输出实际纳入 n、配对/聚类数、系数/对比、SE、CI、p 与校正值、效应量、模型诊断、缺失/排除列表、错误日志、版本、脚本/输入/输出 SHA-256 和退出码。写完代码但未运行只标 NOT_RUN。失败时保留日志，不输出伪造结果。
