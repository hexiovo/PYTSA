# PYTSA 快速开始

适用于 PYTSA 1.3.1 Windows 便携版。

1. 从[发布页](https://github.com/hexiovo/PYTSA/releases/tag/v1.3.1)下载 `PYTSA-1.3.1-Windows-x64.zip`，解压到有写入权限的文件夹。
2. 双击 `RunWithLocalData.cmd`。不需要预装 Python；首次启动会创建程序目录下的 `Data` 工作区。升级时保留已有的 `Data` 文件夹。
3. 在首页点击 **加载通用合成示例**，进入“02 预处理与分析”并点击 **准备数据并分析**，熟悉页面后再导入自己的数据。
4. 导入真实记录时，核对时间列、时区、信号单位和设备采样率；每个文件按一个被试或条件的一段连续记录处理。
5. 完成分析后检查图表、状态和提示，再选择结果文件夹和报告格式导出。项目、模板和历史记录保存在 `Data` 工作区中。

合成示例只用于熟悉操作，不是真实被试、实验或传感器数据。CPU 可直接运行；GPU 和 cvxEDA 求解器为可选功能，详见[操作指南](操作指南.md)。完整界面说明见[操作指南](操作指南.md)，配置、项目和导出细节见[使用说明](使用说明.md)。
