# PYTSA 使用说明

PYTSA 在本机读取表格并运行分析。原始数据文件保持只读；数据预检、区间标注和批次分析都不会自动删除或改写源数据。

## 页面入口

左侧导航包含“数据输入”“预处理与分析”“指标矩阵与图表”“预测、导出与方法”“实验 / 皮电”和“工作台”。项目、模板、数据预检、批量处理、历史比较、区间标注、日志和最近记录都在“工作台”页面。

## 数据预检

在“数据输入”页选择 CSV、TSV、TXT 或 XLSX 文件，然后点击“读取所选工作表 / 格式”。也可以读取剪贴板或载入内置合成示例。每次载入新数据后，工作台会在输入边界进行一次预检；需要重新检查时，打开“工作台”→“数据预检”，点击“对当前选择重新预检”。

预检结果会列出检查项、列名、数量、行位置、时间范围和说明。检查包含缺失值、重复时间、采样不规则、常量列，以及按 1.5×IQR 标记的异常范围。预检只报告发现，不会填补、删除、重采样或排除数据；1.5×IQR 结果也只是标记，不代表自动剔除。

## 常用参数与指标（1.2.0）

“数据输入”新增“时间单位与时区”：数值时间支持 `s`（秒）、`ms`（毫秒）、`us`（微秒），进入分析后统一为秒。日期时间中的无时区值按填写的时区解释，例如 `Asia/Shanghai`；默认 `UTC`。有时区值转换为 UTC。夏令时重复或不存在的本地时间会报错，需要明确输入偏移。预检、连续标签事件映射和批次使用相同时间设置。独立事件表仍使用相对记录起点的秒数。

“预处理与分析”新增以下设置：

- **填补上限**：最大填补时长（秒）与最大连续缺失点数，留空不限制。连续缺失时长为缺失点数除以采样率；设置两项时同时检查。超过上限会停止准备数据。填补仍只作用于探索分支。
- **通用滤波**：Butterworth 低通 `lowpass`、高通 `highpass`、带通 `bandpass`，默认 `none`。低通填写上限，高通填写下限，带通填写上下限；频率须严格位于 0 与 fs/2 之间。阶数为 1–12。`zero` 双向零相位滤波需要足够长的记录；`causal` 为单向因果滤波，初始状态为零。滤波在填补后、探索性变换前执行；预测与皮电继续使用保留的物理值分支。
- **Welch 设置**：窗函数 `hann`、`hamming`、`blackman`、`boxcar`；重叠比例默认 0.5；FFT 点数留空时等于有效分段长度，填写值不能小于有效分段长度；去趋势可选 `constant`（去均值）、`linear`（去线性趋势）、`none`。PSD 和相干使用一致设置。
- **滑动统计**：窗口长度留空则关闭；可填写步长或重叠比例。明确步长优先；否则步长为窗口长度乘以（1−重叠比例）。通用窗口长度与步长四舍五入到最近采样点；末尾不完整窗口保留并标记 `PARTIAL`。起止时间相对首个预处理后样本，区间为左闭右开。最多生成 100000 行窗口结果。
- **功率频段**：整体描述统计中的 `band_power` 使用上方“相干频带”上下限。多个命名频段可填 `slow:0:0.5;fast:0.5:5`，频率单位 Hz，实际范围须符合本次 fs/2，名称不能重复。

描述统计新增样本方差 `variance`（ddof=1）、峰峰值 `peak_to_peak`、四分位数 `q1/q3`、未缩放中位数绝对偏差 `mad`、总功率 `total_power`、频带功率 `band_power`、相对功率 `relative_band_power`、频谱质心 `spectral_centroid`。功率使用 PSD 梯形积分并对频带边界插值；奇数 FFT 的最高频点低于 fs/2，只积分已有频率范围。功率单位为信号单位的平方，相对功率为比例，质心为 Hz；总功率为零时相对功率和质心为 NA。新增“频段功率”和“滑动统计”结果标签，可横向滚动查看全部指标列。

“实验 / 皮电”新增窗口步长与重叠比例。窗口汇总增加 SCL 标准差和每秒线性斜率、SCR 幅值中位数/最大值、上升时间均值/中位数、半恢复时间均值/中位数及有效恢复数量。无峰时幅值与时间汇总为 NA；半恢复未出现的峰不计入恢复时间均值，`scr_recovery50_n` 显示有效数量。

事件基线校正支持 `subtract_mean`（默认，减基线均值）、`subtract_median`（减基线中位数）、`none`、`ratio`（响应除以基线均值）和 `percent`（相对基线均值变化百分比）。新增 `corrected_response_mean` 与有符号面积 `response_auc`；原有 `delta_mean` 始终保留响应均值减基线均值的定义。AUC 对响应窗中实际采样点做梯形积分，不延伸至右端点；缺段、越界、重叠事件的 AUC 为 NA。比值/百分比模式基线为零时标记 `ZERO_BASELINE`。AUC 单位为校正后单位乘秒，例如 uS·s、%·s。

“无响应”定义为有效事件响应窗中没有符合检测阈值的 SCR 起始点。标签汇总增加 `nonresponse_count` 和 `nonresponse_fraction`，比例分母仅包含状态为 `OK` 的事件；没有有效事件时比例为 NA。

“预测、导出与方法”新增可调留后比例（默认 0.2）、预测区间置信水平（默认 0.95）和附加滚动验证。置信水平用于 ARIMA/SARIMA；未提供模型区间的方法继续显示 NA。选择 `rolling` 后，可设置固定训练窗口、每折验证长度和滚动步长（均为样本点）；留空时分别使用半段记录、未来预测长度、每折验证长度。训练窗口至少 16 点，完整验证折必须落在记录内。每折只使用其之前的数据，因果填充也仅在该训练窗内进行；验证实际值不填补。结果新增“滚动误差”和“滚动预测”标签。重叠验证折单独保留，不把重复时间点合并。最多 500 次滚动模型拟合及 2000000 行滚动预测。

新增设置随参数模板、项目、批次和历史快照保存。旧模板未包含的新增设置恢复为默认值。CSV/XLSX/HTML 包含新增表格，JSON 新增 `result_tables`，保存指标和预测表；窗口状态与缺失结果会保留。

## 项目保存、恢复与源文件迁移

1. 打开“工作台”→“项目”，填写“项目名称”。
2. 首次保存点击“另存为…”，选择保存位置；后续可用“保存项目”更新当前项目，或再次点击“另存为…”创建另一份项目文件。
3. 打开项目时点击“打开项目…”，选择 `.pytsa.json`、`.json` 或 `.zip` 文件。

项目文件内嵌当前表格、事件表、参数、可用分析结果、界面设置、预检状态和人工标注。恢复项目时，程序从项目内嵌数据恢复结果，不会自动重读源文件。

恢复时会显示原始源文件状态：`unchanged` 表示原路径存在且文件大小、修改时间与保存项目时记录的一致；`changed` 表示大小或修改时间不同；`missing` 表示原路径不可用；`unknown` 表示无法判断。即使源文件缺失或变化，项目内嵌数据和已保存结果仍可恢复。

如果源文件已移动或你想改用另一份文件，程序不会自动搜索或替换路径。请到“数据输入”页点击“选择文件”，选中新位置的文件，再点击“读取所选工作表 / 格式”。载入新来源会清除当前派生结果和标注；完成重新分析后，再保存项目即可记录新的来源路径和结果。

## 参数模板

在“工作台”→“参数模板”中管理预处理、分析、预测、皮电和事件列设置。

1. 在“名称”填写模板名，在“保存范围”选择 `combined`、`prepare`、`analysis`、`forecast` 或 `eda`。
2. 点击“保存当前设置”保存当前界面参数；重复名称会询问是否覆盖。
3. 在列表选择模板后点击“应用所选”。应用只更新界面设置，不会立即运行分析。
4. 可用“复制”输入新名称，用“导入…”或“导出…”交换 JSON 模板，用“删除”移除选中的模板。

应用模板时，列名、采样率和皮电单位会与当前数据设置比较。模板引用了当前数据中不存在的列时，会要求逐项选择对应列；留空会取消应用。采样率或皮电单位不同时，程序会询问是否采用当前数据设置。其它兼容性问题未解决前，模板不会应用。

## 批量处理

在“工作台”→“批量处理”中点击“添加文件…”，一次选择一个或多个 CSV、TSV、TXT 或 XLSX 文件。可用“移除所选”调整列表，也可为每个输入文件单独指定事件表。

“事件文件策略”必须明确选择一种：

- “无事件文件”：批次不读取外部事件表。
- “所有文件共用事件表”：选择一份共用事件表，并填写事件时间列、事件标签列。
- “逐文件映射事件表”：对每个输入文件分别点击“为所选文件指定事件表…”，并填写事件时间列、事件标签列。每个文件都要完成映射。

程序不会按文件名或列表顺序自动配对事件表。若皮电分析使用输入数据里的连续标签列，可填写“或原始连续标签列”；此时程序会从该列整理事件。事件表时间应为从记录起点算起的秒数。

按需勾选“同时运行预测分支”或“同时运行皮电分支”。启用皮电分支时，需明确选择皮电通道和输入单位。可填写“每个文件输出目录”；留空时，结果保存在本地工作区的 `batch-output` 目录。

点击“开始批量分析”后，结果表会逐文件显示状态、耗时、输出目录、历史 ID 和错误说明。失败项会单独记录，不会阻止后续文件继续处理。每个批次都有 `summary.csv`；点击“打开批量汇总…”可查看。每个成功文件也会生成独立结果目录，并保存一条运行历史。

“重试上次失败项”只重试最近批次中状态为 `failed` 的文件，使用该批次冻结的参数和事件映射，并创建新的子批次。已取消或未开始的文件不会作为失败项重试。重试前会检查输入数据和事件表是否仍与原批次一致；文件缺失或变化时，请创建新批次。

## 运行历史与比较

完成预处理与分析、预测或皮电分析后，程序会自动保存不可变运行快照，其中包含来源、参数、指标、可用曲线和结果摘要。打开“工作台”→“历史比较”，点击“刷新历史”查看最近记录；按住 Ctrl 选择两条记录，再点击“比较所选两次”。

比较结果分为参数、指标和曲线。指标只有在两次运行都有有效数值且单位一致时才计算差值。曲线只在分析类型、横纵轴单位和时间基准一致时叠加；横轴使用从记录起点算起的秒数。单位、时间基准或分析类型不匹配时，界面会显示原因。曲线保留原采样点，不做插值或重采样。

## 区间与人工标注

在时域图或皮电图上横向拖动可选择一个时间区间。选区换算为从记录起点开始的秒数。打开“工作台”→“区间与标注”，填写“标注名称”和可选的“备注”，点击“添加选区标注”；选择已有记录后可“编辑所选”或“删除所选”。标注会随项目保存；导出报告时可在“人工标注”章节中显示。

标注只记录区间，不会自动排除样本或改变分析计算。若要把选区用作皮电窗口和事件统计范围，请在皮电页面点击“用于皮电统计区间”。这只会设置统计起止秒数；皮电信号清理和分解仍处理完整连续信号。更换数据来源后，旧选区会失效，需要重新选择。

## 任务进度与取消

“工作台”顶部的“任务进度与取消”区域显示当前阶段、已完成文件数和耗时。任务运行时可点击“取消当前任务”。取消在安全阶段边界生效；不可中断的核心计算会先返回，再停止后续阶段。

批次取消后，已完成文件及其历史记录会保留；当前文件可能标记为 `cancelled`，后续未开始的文件标记为 `not_run`，汇总 CSV 会记录各自状态。报告导出在阶段边界检查取消请求，临时文件会清理，只有完整输出才会发布。

## 持久日志

打开“工作台”→“持久日志”，点击“刷新日志”查看最近日志。选择一条记录可在下方查看详情；错误记录包含完整 traceback。点击“复制全部日志”可复制当前载入的日志文本。

日志按运行 ID 保存。每个运行 ID 最多保留 3 个轮转文件，单个日志文件约不超过 5 MiB。一次刷新最多载入最近 500 条记录。

## 最近使用

打开“工作台”→“最近使用”，在“类型”中选择“全部”“项目”或“数据”，点击“刷新”。选择记录后点击“打开所选”；双击记录也可打开。表格显示路径和当前是否存在。文件缺失时不会替换成其它路径；请在“数据输入”页重新选择文件，或点击“移除记录”。移除只删除快捷记录，不会删除项目或数据文件。

列表按最近使用时间排列，界面一次显示最多 20 条，工作区最多保留 100 条记录。

## 报告模板与导出

报告模板位于“预测、导出与方法”→“结果导出”页的“报告模板与章节”卡片。选择或输入模板名，在“报告标题”填写 HTML 标题，并可填写“实验/研究”“日期”“对象”“条件”“补充说明”。勾选需要的报告章节和输出格式。

可用的章节包括“数据摘要”“检验结果”“指标矩阵”“预测”“皮电/事件”“提示”“方法说明”和“人工标注”。输出格式为 CSV、XLSX、JSON、PNG 和 HTML。CSV/XLSX 中的数据表不会因为关闭 HTML 章节而删除；章节选择也会控制对应图表是否导出。关闭“提示”章节只隐藏 HTML 警告段落，所选 JSON 仍保留完整警告和复现元数据。至少要选择一种导出格式。

“导出全部可用图表”会选中当前结果可生成的图；取消后可在列表中多选。选择“所选图名”并填写标题，再点击“设置图名”可更改该图的报告标题。图表是否导出还受对应章节开关控制。

报告模板可“刷新”“加载所选”“保存当前为模板”“复制”“导入…”“导出模板…”或“删除”。重复模板名会询问是否覆盖。默认“默认报告”是内置模板，不能直接删除或导出；要保存或交换设置，请先为当前设置填写另一个模板名并保存。JSON 模板版本为 1，包含模板名、标题、实验信息、章节、格式、图表键和图名。

选好导出位置后点击“导出全部结果”。输出位于所选位置下的 `PYTSA_时间戳\PYTSA_results_时间戳` 子目录；同一时间戳发生冲突时会增加序号，不覆盖已生成目录。实际文件取决于勾选格式：CSV 保存数据和表格，XLSX 保存工作表，JSON 保存来源、参数、版本、警告、实验信息、批注及图表清单，PNG 保存选中的图，HTML 保存离线报告。

HTML 图表以内嵌图片保存，所以只选 HTML 时无需额外 PNG 文件。没有选择 CSV 或 XLSX 时，HTML 不显示相应的表格下载链接。HTML 表格最多显示前 200 行；选择 CSV 时可通过链接打开完整表格，选择 XLSX 且未超过 Excel 行数限制时可在工作簿中查看完整表格。用户填写的标题、实验信息、备注、警告和表格内容都会作为文本转义后写入 HTML。

## 本机数据存放位置

Windows 默认工作区是 `%LOCALAPPDATA%\PYTSA`；设置环境变量 `PYTSA_HOME` 后使用该变量指定的位置。工作区在首次写入时创建。参数模板存放在 `templates\parameters`，报告模板存放在 `templates\reports`，最近记录在 `recent.json`，运行历史和批次记录在 `history`，日志在 `logs`。没有指定批次输出目录时，批次结果写入 `batch-output`。

项目文件保存在用户在“另存为…”中选择的位置，不会自动移入工作区目录。模板可通过界面导入/导出 JSON 文件，便于在其他电脑间复制。

## 本地构建（维护者）

构建脚本使用项目 `.venv` 中的 Python 和 PyInstaller。可用 `-DeliveryDir` 指定交付目录；相对路径按项目目录解析：

```powershell
.\build.ps1 -DeliveryDir '.\build\deliver'
```

脚本把程序构建到 `build\dist\PYTSA.exe`，再复制到指定目录并核对文件大小和 SHA-256。省略 `-DeliveryDir` 时保留原有的桌面交付目录默认值。

本地交付使用 `powershell .\build.ps1 -DeliveryDir D:\program\PYTSA\deliver`，应用版本为 `1.2.0`，输出为 `D:\program\PYTSA\deliver\PYTSA.exe`。构建脚本输出实际文件大小和 SHA-256。测试依赖在 `requirements-dev.txt` 中，验证命令为 `.venv\Scripts\python.exe -m pytest -q`。
