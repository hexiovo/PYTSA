# PYTSA 实验设计配置 Skill 使用说明

本说明适用于随 PYTSA 1.3.1 源码发布的 `pytsa-study-config` Skill。它帮助把研究设计整理成可核对的 PYTSA 配置和主试操作包。

## 从设计到操作包

向 Skill 提供研究目的、实验对象与条件、流程时间线、设备和采样信息、事件定义、重复测量或分组安排，以及手头文件的列名和单位。可以用日常语言描述；主试不需要先选定统计检验名称。Skill 会把已知信息整理成配置字段和统计建议，说明选择依据，并集中列出需要研究人员确认的问题。未知信息保持为 `pending`，不会被补写成事实。

按研究需要，输出包可包含 PYTSA 参数模板草案、设计决策台账、数据字典、转换计划或脚本、统计分析计划或独立脚本、主试操作卡和验证记录。操作卡逐步说明文件与列的选择、单位和采样率核对、成功信号、错误恢复和结果保存位置。只有实际运行并验证的步骤才标记为通过；没有执行的内容会标为 `NOT_RUN` 或 `BLOCKED`。

PYTSA 原生分析主要处理单个被试或条件的一段连续记录，不提供通用的实验组间或重复测量推断统计。设计需要这些模型时，Skill 会将统计计划及脚本单独列出，并说明其输入、输出和验证状态；不会把它们伪装成 PYTSA 的原生功能。用户确认设计与数据契约后，再导入参数模板、核对当前数据映射并由主试启动分析。

## 使用边界

PYTSA 参数模板只保存界面设置，应用模板不会自动计算。生成的配置、代码和统计建议都需要根据实际设计、数据字典和软件版本复核。AI 辅助不能保证配置或分析必然正确；若没有实际运行工具，Skill 不会声称已经在 PYTSA 执行。示例数据带有合成数据标记，只用于理解格式和流程。

详细流程见 [Skill 源码](../skills/pytsa-study-config/SKILL.md)，包括输入决策、参数契约、数据转换、统计方案、操作卡和来源链接。示例目录内的 `expected-manual.json` 是人工预期结果；`run_example.py` 是实际生成器。运行脚本会产生输出文件，请在需要时自行运行；生成结果不作为真实研究结果。
