# PYTSA 1.3.1 发布说明

PYTSA 1.3.1 提供 Windows x64 便携版及可独立使用的源码。便携版无需预装 Python，CPU 模式可直接运行。

## 下载与启动

- [GitHub v1.3.1 发布页](https://github.com/hexiovo/PYTSA/releases/tag/v1.3.1)
- [PYTSA-1.3.1-Windows-x64.zip](https://github.com/hexiovo/PYTSA/releases/download/v1.3.1/PYTSA-1.3.1-Windows-x64.zip)

将压缩包解压到有写入权限的位置，双击 `RunWithLocalData.cmd`。首次启动会创建 `Data` 工作区；升级时请保留已有的 `Data`。该启动器将项目、参数模板、报告模板、运行历史、日志和批次结果保存到此工作区。运行资源设置和可选依赖环境保存在 Windows 用户配置目录。移动或备份便携版时，请同时保留程序文件和 `Data`。

## 主要能力

- 导入常见表格并设置时间、时区、采样率、缺失处理、重复时间和重采样规则。
- 使用描述统计、平稳性检验、ACF/PACF、STL、Welch 频谱、Pearson/Spearman/Kendall 矩阵、偏相关、滞后相关、相干和距离矩阵。
- 比较 Naive、SeasonalNaive、ETS、ARIMA 和 SARIMA 预测，并运行时间留后或滚动验证。
- 进行皮电清理、分解、SCR 检测、窗口汇总和事件分析。
- 保存项目、参数与报告模板、运行历史和批次记录；导出 CSV、XLSX、JSON、PNG 或离线 HTML。
- 选择性启用探索性滤波、平滑、Hampel 去尖峰、小波处理及 Hjorth、排列熵、线长和过零率等描述指标。

## 计算环境与限制

CPU 是默认计算路径。GPU 加速为可选项，需要兼容的 NVIDIA GPU、驱动和 CuPy 组件，目前覆盖 Pearson、协方差和标准化距离矩阵。环境检测会执行实际运算；软件安装不会安装显卡或驱动。cvxEDA 需要可选依赖 `cvxopt`。BioSPPy 清理要求采样率高于 10 Hz；SparseEDA 仍属实验性方法，可能失败。

输入文件按单个被试或条件的一段连续记录处理，程序不会自动拼接多名被试或连接采集设备。合成示例仅用于熟悉操作。相关、相干、预测和皮电结果需要结合采样、实验设计、单位和模型假设解释；它们本身不代表因果关系、心理状态或临床诊断。实验组间和重复测量推断分析需使用单独的统计方案，参见 [Skill 使用说明](Skill使用说明.md)。
